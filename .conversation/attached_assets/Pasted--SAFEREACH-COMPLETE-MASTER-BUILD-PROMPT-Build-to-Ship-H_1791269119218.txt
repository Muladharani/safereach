# 🚨 SAFEREACH — COMPLETE MASTER BUILD PROMPT

## Build-to-Ship Hackathon Project

Build a complete, polished, production-style, responsive full-stack web application called:

# 🛡️ SafeReach

### Tagline:

**Find Safety. Reach Shelter. Stay Safe.**

SafeReach is a smart emergency shelter discovery and disaster-response platform that helps people find nearby safe shelters during:

* 🌊 Floods
* 🌀 Cyclones
* 🌎 Earthquakes
* ⛈️ Severe storms
* 🔥 Wildfires
* 🌧️ Heavy rainfall
* 🌊 Tsunamis
* 🚨 Other emergency situations

The application should help users:

**Receive emergency alerts → Find nearby shelters → Check availability → Find the most suitable shelter → Get directions → Reach safety.**

This project is being built for a **Build-to-Ship Hackathon**.

Do NOT build this like a basic college project or static website.

Build it like a **real startup product that could be demonstrated to judges, users, NGOs, disaster-management teams, and potential investors.**

---

# 1. CORE PRODUCT VISION

The main problem:

During a disaster, people may not know:

* Where the nearest shelter is
* Whether it is open
* Whether it has space
* Whether food/water/medical facilities are available
* Whether the shelter is accessible
* How to reach it
* Whether roads are blocked
* What emergency action they should take
* Where to get reliable emergency information

SafeReach solves this by putting all important information into one simple platform.

### Core experience:

```text
🚨 DISASTER ALERT
       ↓
🔔 USER NOTIFIED
       ↓
📍 LOCATION DETECTED
       ↓
🏠 NEARBY SHELTERS FOUND
       ↓
📊 AVAILABILITY CHECKED
       ↓
🤖 BEST SHELTER RECOMMENDED
       ↓
🗺️ DIRECTIONS PROVIDED
       ↓
🛡️ USER REACHES SAFETY
```

# 30. IMPORTANT SIREN RULE

Do NOT automatically play loud audio on page load.

2. Show a clear PLAY SIREN button.
